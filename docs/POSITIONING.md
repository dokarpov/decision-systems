# Positioning

Decision Systems is not a workflow engine, agent framework or dashboard.

It is a **minimal decision contract** between signals and actions.

The value is reducing ambiguity at the exact point where a workflow must decide:

> What happened → What next → Who decides

Use it before designing:
- automation
- approval flows
- AI agent permissions
- operational queues
- support escalation
- internal tools

The interface can change. The decision contract should remain simple.
